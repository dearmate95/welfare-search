지금 만지는 컨트롤

컨트롤에 마우스를 올리거나 조작해 보세요

노브는 위아래로 드래그(또는 휠), 버튼은 클릭, 페이더는 드래그합니다. 더블클릭하면 기본값으로 돌아갑니다.

채널 분석

구간별 레벨 (0 dB = 기준 레벨, +20 dB에서 찌그러짐)
EQ 곡선 + 실시간 스펙트럼
컴프레서
게인 리덕션
0.0 dB
이 채널은 어디로 가나
소리가 안 날 때 점검 순서

    버스 레벨

    사용법

    1. ⏻ POWER를 켭니다. (브라우저 정책상 클릭해야 소리가 납니다)
    2. 입력 장비 카드를 눌러 채널에 꽂고, 출력 장비 카드를 눌러 STEREO OUT·AUX SEND 등에 꽂습니다. 믹서의 단자를 직접 눌러도 됩니다.
    3. ▶ 연주 시작을 누르면 연결된 장비에서 신호가 나옵니다.
    4. GAIN → ON → 채널 페이더 → ST 스위치 → STEREO ON → STEREO 페이더 순으로 올려 소리를 냅니다.
    5. 오른쪽 패널에서 구간별 레벨, EQ 곡선, 컴프레서 동작, 신호 경로 점검표가 실시간으로 바뀝니다.

    조작 · 노브: 위/아래 드래그 또는 마우스 휠 (Shift = 미세 조정) · 버튼: 클릭 · 페이더: 드래그 · 더블클릭: 기본값

    듣는 위치 · 객석 = 메인 스피커 / 무대 = 모니터(웨지) 스피커 / 조정석 = MONITOR OUT 스피커 / 헤드폰 = PHONES / USB 녹음 = 노트북에 녹음되는 소리

    빠른 시작 · 「⚡ 밴드 세팅 한번에」를 누르면 연결과 기본 믹스가 자동으로 잡힙니다. 「🔌 기본 연결만」은 케이블만 꽂고 조작은 직접 해 보는 실습용입니다.

    ※ 실제 제품을 학습 목적으로 본뜬 비공식 시뮬레이터입니다. 소리와 수치는 원리를 이해하기 위한 근사값이며, 실제 기기의 세부 사양은 제조사 사용설명서를 확인하세요.
