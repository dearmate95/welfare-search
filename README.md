# 복지사례 문서검색

사회복지 사례관리를 위한 **내 컴퓨터 안 문서 검색·비교분석 프로그램**입니다.

이용인 이름이나 `사례관리록`, `초기상담` 같은 단어를 입력하면,
컴퓨터 안에 흩어져 있는 한글·워드·엑셀·PDF·텍스트 문서에서
그 단어가 들어간 파일을 한 번에 찾아 줍니다.
찾은 문서들을 모아 **주요 키워드, 기록 기간, 빠진 서식**까지 정리해 줍니다.

> **모든 처리는 내 컴퓨터 안에서만 이루어집니다.**
> 인터넷으로 어떤 자료도 보내지 않으며, 설치할 별도 프로그램도 없습니다.

---

## 1. 설치와 실행

### 준비물
파이썬(Python) 3.9 이상 하나면 됩니다. 다른 설치는 필요 없습니다.
- 없다면 <https://www.python.org/downloads/> 에서 설치
- **윈도우 설치 시 화면 아래 `Add Python to PATH` 를 꼭 체크**하세요.

### 실행
| 운영체제 | 방법 |
|---|---|
| 윈도우 | `실행_Windows.bat` 더블클릭 |
| 맥·리눅스 | `실행_Mac_Linux.command` 더블클릭 (처음 한 번 `chmod +x` 필요) |
| 직접 실행 | 명령창에서 `python main.py` |

실행하면 검은 명령창이 하나 뜨고, 이어서 **브라우저 화면**이 자동으로 열립니다.
명령창은 프로그램 본체이므로 사용 중에는 닫지 마세요. (종료하려면 `Ctrl+C`)

### 처음 한 번만 하는 설정
1. 브라우저 화면에서 **`폴더·색인`** 탭으로 갑니다.
2. **`＋ 폴더 추가`** 를 눌러 사례관리 문서가 들어 있는 폴더를 고릅니다.
   (`문서` 폴더처럼 상위 폴더 하나만 지정해도 그 아래 전부 찾습니다.)
3. **`색인 시작 / 갱신`** 을 누릅니다.
   문서를 읽어 검색용 목록을 만드는 과정으로, 문서가 많으면 시간이 걸립니다.
4. 다음부터는 **새로 만들거나 고친 파일만** 빠르게 갱신됩니다.

## 2. 화면 사용법

### 검색 탭
검색창에 이용인 이름이나 찾을 단어를 넣고 엔터를 누릅니다.

| 입력 예시 | 뜻 |
|---|---|
| `홍길동` | 홍길동이 들어간 모든 문서 |
| `홍길동 상담` | 두 단어가 **모두** 들어간 문서 |
| `"초기 상담"` | 따옴표 안 문구 그대로 |
| `홍길동 -종결` | 홍길동 문서 중 `종결`이 든 것은 **제외** |
| `홍길동 \| 김영희` | 둘 중 **하나라도** 들어간 문서 |

- 한국어 조사를 신경 쓸 필요가 없습니다. `홍길동`으로 찾으면 `홍길동은`, `홍길동이`, `홍길동님` 모두 걸립니다.
- 결과를 누르면 **본문 미리보기**가 열리고, 원본을 열지 않고도 내용을 확인할 수 있습니다.
- `파일 열기`·`폴더 열기`로 원본을 바로 열 수 있습니다.
- `결과 CSV 저장`으로 목록을 엑셀에서 열 수 있게 내려받습니다.

### 이용인 분석 탭
이름을 넣으면 그 사람 관련 문서를 모두 모아 한 장으로 정리합니다.

- **기록 요약** — 관련 문서 수, 기록 기간, 필수 서식 확보 현황
- **필수 서식 점검** — 초기상담지 / 욕구사정 / 서비스제공계획서 / 상담·과정기록 /
  모니터링 / 종결·사후관리 / 개인정보 동의서 중 **확인되지 않은 것**을 표시
- **기록 공백 구간** — 3개월 이상 기록이 비어 있는 기간
- **영역별 비중** — 경제·건강·주거·안전·가족·교육고용·자원연계·정서지원
- **주요 키워드** — 자주 나온 단어와 등장 문서 수 (눌러서 바로 재검색)
- **함께 나오는 이름·기관** — 관련 인물과 연계 기관

### 비교분석 탭
두 대상(이용인 A와 B, 또는 두 단어)을 나란히 견줍니다.

- **영역별 비중 비교** — 어느 쪽이 어떤 영역에 치우쳐 있는지
- **공통 키워드** — 두 사례에 함께 나타나는 주제
- **각자에게만 두드러진 키워드** — 상대빈도 차이로 뽑은 특징 단어

같은 이용인의 서로 다른 시기를 비교하거나(`홍길동 2023` vs `홍길동 2024`),
사업 단위를 비교하는 데(`긴급복지` vs `자활`) 쓸 수도 있습니다.

## 3. 읽을 수 있는 파일

| 종류 | 확장자 | 비고 |
|---|---|---|
| 한글 | `.hwp` `.hwpx` | 별도 설치 없이 본문을 읽습니다 |
| 워드 | `.doc` `.docx` | |
| 엑셀 | `.xls` `.xlsx` `.xlsm` | 명단·관리대장을 행 단위로 읽습니다 |
| 파워포인트 | `.ppt` `.pptx` | |
| 텍스트 | `.txt` `.md` `.csv` `.rtf` 등 | UTF-8과 CP949(옛 윈도우) 모두 |
| PDF | `.pdf` | `pip install pypdf` 를 하면 본문까지 읽습니다 |

- 암호가 걸린 문서, 스캔(사진)으로 된 PDF는 본문을 읽을 수 없습니다.
  이 경우에도 **파일명은 검색**됩니다.
- 읽지 못한 파일은 `폴더·색인` 탭에서 목록으로 확인할 수 있습니다.

## 4. 개인정보 보호

사례관리 기록은 민감정보입니다. 아래를 지켜 주세요.

- 이 프로그램은 **인터넷 연결을 전혀 사용하지 않습니다.** 화면은 `127.0.0.1`(내 컴퓨터)에서만 열리며,
  실행할 때마다 만들어지는 일회용 접속키가 있어야 열립니다.
- 색인 파일에는 **문서 본문이 그대로 담깁니다.** 저장 위치는 `폴더·색인` 탭 맨 아래에 표시됩니다.
  (기본값: 사용자 폴더의 `.welfare_search/index.db`)
- **공용 PC에서 사용했다면** 사용 후 `색인 완전 삭제`를 눌러 주세요. 원본 문서는 지워지지 않습니다.
- USB나 공유 폴더에 색인 파일을 복사하지 마세요.
- 이 프로그램의 분석은 **기계적 추정**입니다. 서식 점검 결과나 키워드는 참고 자료일 뿐이며,
  실제 기록 관리·평가 판단은 반드시 담당자가 확인해야 합니다.

## 5. 명령줄로 쓰기 (선택)

화면 없이 명령창에서 바로 쓸 수도 있습니다.

```bash
python main.py add "D:\사례관리"      # 검색할 폴더 추가
python main.py index                  # 색인 만들기 (--full 은 처음부터 다시)
python main.py find 홍길동 상담         # 검색
python main.py profile 홍길동          # 이용인 기록 요약
python main.py compare 홍길동 김영희    # 두 대상 비교
python main.py status                 # 현재 상태
```

## 6. 자주 묻는 것

**Q. 검색이 안 돼요.**
`폴더·색인` 탭에서 폴더가 등록돼 있고 색인이 끝났는지 확인하세요.
새로 만든 문서는 `색인 시작 / 갱신`을 눌러야 검색됩니다.

**Q. 파일을 옮기거나 지웠어요.**
`색인 시작 / 갱신`을 한 번 누르면 없어진 파일은 목록에서 자동으로 빠집니다.

**Q. 한글 파일 본문이 안 읽혀요.**
암호가 걸렸거나 아주 오래된 형식(HWP 3.0 이하)일 수 있습니다.
한글에서 열어 최신 형식으로 다시 저장한 뒤 색인하세요.

**Q. 색인이 너무 오래 걸려요.**
`폴더·색인` 탭에서 필요 없는 파일 형식의 체크를 해제하거나,
문서가 실제로 모여 있는 하위 폴더만 지정하세요.

**Q. 이름이 두 글자예요.**
두 글자도 검색됩니다. 다만 다른 단어에 우연히 포함될 수 있으니
`김철 상담`처럼 단어를 하나 더 넣으면 정확해집니다.

## 7. 개발자용 메모

```
main.py                  실행 진입점
wsearch/
  config.py              설정 저장/불러오기
  db.py                  SQLite 스키마 (FTS5 trigram 색인)
  korean.py              조사 제거, 사회복지 용어 사전, 서식 유형 판별
  extract/               파일 종류별 본문 추출
    cfb.py               OLE 복합문서 리더 (외부 라이브러리 없이 .hwp/.doc/.xls 처리)
    hwp.py hwpx.py       한글 문서
    ooxml.py msdoc.py    MS 오피스 (신·구 형식)
    plain.py rtf.py pdfdoc.py
  indexer.py             폴더 훑기 + 증분 색인
  search.py              검색어 해석, 후보 좁히기, 본문 대조, 스니펫
  analyze.py             프로필·비교·체크리스트·추이
  server.py              로컬 웹 서버 (토큰 인증, 127.0.0.1 전용)
  webui/index.html       화면 전체 (외부 라이브러리 없음)
tests/                   테스트 (python -m unittest discover -s tests -t .)
```

한글 검색은 조사 때문에 단어 경계가 흐려서, SQLite FTS5의 `trigram` 토크나이저로
부분일치 후보를 좁힌 뒤 본문을 직접 대조해 정확도를 보장합니다.
3글자 미만 검색어는 trigram 색인을 쓸 수 없어 `LIKE` 로 처리합니다.
